PROJECT 1 – DESCRIPTION

This program is a simple vegan shop manager that saves and loads data from a storage.json file.

It uses several functions defined in the vegan_functions (vf) module to perform operations such as adding products, 
selling them, listing them, and more.

-----------------------------------------------------------------------------------------------------------------------

PROGETTO 1 - DESCRIZIONE

Questo programma è un semplice gestore di negozio vegano che salva e carica i dati da un file storage.json.

Utilizza diverse funzioni definite nel modulo vegan_functions (vf) per compiere operazioni come aggiungere prodotti, 
venderli, elencarli, ecc.
